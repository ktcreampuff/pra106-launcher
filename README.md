# PRA106 Launcher

PORMIDO PRA106（Android車載ディスプレイオーディオ）向けの自作ホームランチャーです。

## できること
- インストール済みアプリをグリッド表示するだけのシンプルなホーム画面
- ホームボタンを押した時の挙動は通常のAndroidと同じ（タスク切り替えはOS標準に任せている）
- 画面上部に時計・戻るボタン・ホームボタンを重ねて表示する簡易バー（追加表示。root権限がないため、PRA106純正のステータスバーは消せない）

## 初回セットアップ（本体側）
1. このAPKをインストールし、ホームアプリの選択で「PRA106 Launcher」を選ぶ
2. アプリを開くと、権限許可のバナーが出る
   - 「他のアプリの上に重ねて表示」を許可
   - 「設定 > ユーザー補助」で「PRA106 Launcher」をオンにする（戻るボタンの動作に必要）
3. 両方許可すると、自動で簡易ステータスバーが表示される

## ビルド
GitHub Actions（`.github/workflows/build.yml`）で自動ビルドされます。`main`ブランチにpushすると、
- Actionsタブの実行結果からAPKをダウンロードできます
- 合わせてReleasesにもAPKが添付されます
